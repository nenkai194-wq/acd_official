### 2. Backend & Arsitektur
- **Framework**: Python Flask 3.x
- **Database**: SQLite terstruktur dengan auto-initialization & rich seeder
- **RESTful API**:
  - `POST /api/v1/consultation` (Simpan leads konsultasi)
  - `POST /api/v1/estimate` (Kalkulasi estimasi biaya & timeline)
- **Admin Portal CMS (`/admin`)**:
  - Autentikasi sesi staf aman
  - Pemantauan metrik leads & layanan
  - Manajemen status prospek calon klien (Baru, Dihubungi, Follow-up, Deal)
  - Tombol aksi langsung hubungi WhatsApp calon klien

## 🚀 Cara Menjalankan Aplikasi

1. **Pastikan Python terpasang** (Python 3.10+ disarankan).
2. **Jalankan server Flask**:
   ```bash
   python app.py
   ```
3. **Buka di Browser**:
   - Website Publik: [http://localhost:5000](http://localhost:5000)
   - Portal Admin: [http://localhost:5000/admin](http://localhost:5000/admin)
