Panduan Pengoperasian Modul CMS (SOP Administrator)

Langkah-langkah praktis dalam mengoperasikan dan mengelola setiap modul website

1. Mengelola Leads Masuk & Follow-Up

  • Buka menu Permintaan Masuk untuk meninjau formulir kebutuhan klien.
  • Gunakan tombol Follow-Up via WA untuk langsung chat WhatsApp klien dengan draft salam pembuka otomatis dari sistem ACD.
  • Perbarui status leads menjadi Dihubungi, Diproses, atau Selesai dan catat hasil pembicaraan pada field catatan internal.

2. Mengelola Katalog Solusi & Layanan

  • Buka menu Kelola Layanan untuk menambah atau mengedit layanan solusi IT.
  • Pilih kategori yang tepat (Pemerintahan, ERP, Mobile Apps, AI & Data, Cloud).
  • Tentukan status Tayang agar langsung terbit di halaman publik atau Draft jika masih dipersiapkan.

3. Mengelola Portofolio & Studi Kasus

  • Buka menu Kelola Portofolio untuk mendokumentasikan proyek yang berhasil diselesaikan ACD.
  • Lengkapi tantangan klien (challenge), solusi implementasi ACD, dan metrik dampak positif proyek.
  • Data portofolio otomatis ditampilkan di showcase halaman utama dan halaman portofolio resmi.

4. Mengelola Lowongan Karir & Rekrutmen

  • Buka menu Karir & Lowongan untuk membuka lowongan posisi baru talenta teknologi.
  • Atur jenis penempatan (Onsite, Hybrid, atau Remote) serta poin persyaratan dan tanggung jawab.
  • Pelamar dapat langsung mengirim CV dan portofolio ke email karir resmi dengan subjek terformat.

5. Mengatur Optimasi SEO & Indeks Mesin Pencari

  • Buka menu Optimasi SEO untuk mengatur Meta Title, Description, dan URL kanonikal resmi.
  • Sistem secara dinamis menyajikan file /sitemap.xml dan /robots.txt tanpa perlu update manual.
  • Masukkan kode tag verifikasi Google Search Console untuk verifikasi kepemilikan domain instan.

6. Monitoring Keamanan & Buka Blokir IP

  • Buka menu Keamanan & Audit Log untuk memantau percobaan akses ilegal dan bot scanning.
  • Jika ada staf yang terkunci akunnya karena 3x salah memasukkan kata sandi, klik tombol hijau Buka Blokir pada daftar IP.
  • Sesi login otomatis terkunci setelah 15 menit idle demi mencegah penyalahgunaan saat komputer ditinggalkan.

Prosedur Pencadangan (Backup) & Pemulihan (Restore)

Panduan menjaga kontinuitas data website dan pemulihan darurat

Seluruh data website (pengaturan, leads klien, layanan, portofolio, lowongan, dan log keamanan) tersimpan dalam satu berkas terintegrasi: acd_database.sqlite.

Cara Backup Data:
  1. Salin berkas acd_database.sqlite di root direktori proyek.
  2. Simpan berkas salinan ke cloud storage (Google Drive / S3) dengan format penamaan tanggal (contoh: acd_db_backup_20261108.sqlite).
Cara Restore Data:
  1. Hentikan sementara proses web server (Gunicorn / Waitress).
  2. Gantikan berkas acd_database.sqlite dengan berkas cadangan Anda.
  3. Jalankan kembali web server. Data langsung pulih 100% tanpa konfigurasi ulang.
